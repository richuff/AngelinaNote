# Angelina Fonts

Place project-owned font files in this directory. Prefer web-ready `.woff2` files; `.ttf` and `.otf` may be kept as source files.

When adding a custom font, declare it with `@font-face` in `src/styles.css`, reference it with a relative URL such as `../Angelina/Fonts/MyFont.woff2`, and add it to the font menu in `src/index.html`.

Only include font files whose license permits redistribution with the application.
